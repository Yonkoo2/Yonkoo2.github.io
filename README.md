# YonKoo Hexo Site

This repository is set up as a Hexo 8.1.1 site using the local `fett` theme.

The root HTML/CSS/JS files are the currently published GitHub Pages output. The Hexo source lives in:

- `_config.yml`
- `source/`
- `themes/fett/`

When npm is available, install and build with:

```bash
npm install
npm run build
```

The imported SQL article is kept as raw HTML at `source/posts/attacking-sql-databases/index.html` and is listed through `source/_posts/attacking-sql-databases.md` so tags, categories, recent posts, and search can be generated by the theme.
